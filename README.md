# F1vr – OpenF1 Live Data Visualizer for Meta Quest 3

Unofficial fan project that shows a 3D race track with live car positions powered by the [OpenF1 API](https://openf1.org).

Inspired by Lapz (Vision Pro).

## Features (current)
- Live / historical car positions via OpenF1 `/location`
- Smooth car movement on 3D track
- Basic timing data

## Requirements
- Unity 2022.3 LTS or Unity 6
- Meta XR All-in-One SDK (or OpenXR + Meta packages)
- Meta Quest 3 / 3S

## Disclaimer
This is an unofficial fan project.  
Not affiliated with Formula 1, FIA, Liberty Media or Meta.  
Data comes from the open-source OpenF1 project.

## Setup
1. Clone this repo
2. Open the project in Unity
3. Install Meta XR SDK via Package Manager
4. Open `Assets/Scenes/MainRace.unity`
5. Press Play (or build to Quest)
